Install

  1. Download and unzip. You get one folder, QuestBank.
  2. Put it in Interface\AddOns, next to your other addons.
  3. Log in and type /qb.
QuestBank Uploader for Windows does steps 1 and 2 (QuestBank 5.4.4, 859 KB) Unzip anywhere, double-click Install.bat. It also sends your notes in.

Share what you discover

Forever is still being discovered: send in QuestBank's saved file and what it noted reaches everyone in the next release. Windows: QuestBank Uploader does it for you.

Upload by hand

Your notes are in WTF\Account\<account>\SavedVariables\QuestBank.lua under the game folder, written when you log out or /reload. Drop that file here.

No account, no login. The same file can be sent again after every session; only what's new counts.

QuestBank talks only to other QuestBank users in game (party, guild, a version check) and sends nothing to us unless you upload its saved file; uploads stay private, and only quest, NPC and item facts, never names, reach the next release.

Help

It says the addon is out of date

Tick Load out of date AddOns on the character screen.

I see a Lua error

Type /qb errors: a box opens with each problem, already selected, so Ctrl+C copies it for the Discord. Check that QuestBank.toc sits directly in Interface\AddOns\QuestBank, not a folder deeper.

The XP differs from the plan

The chat line after a hand-in shows both numbers. From then on QuestBank uses the game's number and shares it with your party; upload your file and the next release carries it for everyone.

It offers a quest I did already

Type /qb done and the quest's name to see what the game says about it. If a quest you did before QuestBank still shows, tell the Discord its name.

Do I need TomTom?

No. Waypoints show on QuestBank's own arrow, and a link in chat puts the game's map pin there. With TomTom installed, it gets them too.

Does it accept or hand in for me?

Only if you choose so in Settings: Accept for me and Hand in finished quests for me are off on a new install. Hold Shift at an NPC and it keeps its hands off.

How do I update?

Unzip the new QuestBank over the old folder; your plan and settings are kept. QuestBank users tell each other when a newer one is out, and /qb update copies the download link.
